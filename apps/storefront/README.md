# Storefront

The customer-facing half of the system. Shop owners browse the catalogue, ask to
buy, and ask for parts we do not stock; the office answers from `apps/web`.

Started with the rest of the stack:

    npm run dev        # from the repo root — API, office and store

Or on its own:

    PORT=3002 npm run dev

It needs `.env.local` (gitignored, one line):

    NEXT_PUBLIC_API_URL=http://localhost:3001/api/v1

## What is different from `apps/web`

- **Arabic is the default locale**, not a translation of an English app.
- It reaches only `/portal/*` and `/auth/portal/*`. A 403 `WRONG_SURFACE` means
  this app asked for something the office owns — see
  `apps/api/src/common/surface.ts`.
- It is a **separate origin**, so a token stored here is invisible to the office
  app and vice versa. That is the design, not an accident.
- It is a **PWA**: `app/manifest.ts`, `public/sw.js`, and icons generated by
  `node scripts/make-icons.mjs`.

Shared conventions — coded refusals, the `Select`, the pointer-cursor rule —
live in `CLAUDE.md` and `.claude/LEARNINGS.md` at the repo root and apply here.
