# U0 — Shared UI pieces

Branch `feature/ux-u0`, code commit `2e4e152`. No page was changed to use these; U1, U4 and U5 do that.

## What later tasks import

| Import | API |
|---|---|
| `@/components/ui/empty-state` | `<EmptyState title description? action? icon? className? />` — `action` is `{ label, onClick }` or `{ label, href }` (locale-aware `Link`); `icon` is a lucide component or a node, default inbox, `null` for none. All strings come in translated. |
| `@/components/ui/date-picker` | `DatePicker` and `Calendar` gain `disableFuture?: boolean`: days after **Cairo's** today are disabled, "Today" picks Cairo's day, an earlier `max` still wins. Off by default. |
| `@/lib/dates` | `businessToday(now?) → 'YYYY-MM-DD'` in Africa/Cairo · `formatDate(iso, { includeTime?, locale? })` · `timeAgo(iso, { locale? })` · `useDateFormat() → { formatDate, timeAgo }` bound to next-intl's locale. |
| `@/lib/labels` | `useCodeLabel() → (kind, code) => string`, `kind` ∈ orderStatus, paymentStatus, cycleStatus, legStatus, role, paymentMethod, costBasis, customerType, channel. Unknown → the code; empty → `—`; lower-case legacy methods are read upper-cased. |

## Decisions

- **Arabic dates use Latin digits** with Arabic month names (`ar-EG`, `numberingSystem: latn`),
  matching the picker's header and every money figure. English output is byte-for-byte as before.
- **`formatDate` cannot call a hook**, so the plain function takes `locale` (default `en`) and
  `useDateFormat()` is the next-intl reader. Pages switch to the hook in later tasks; until then
  they read English as before. The date picker's own trigger already uses the hook.
- **`codes` values** come from the Prisma enums and the string columns the services set:
  `paymentStatus` is Payment.status (RECORDED, REVERSED); `legStatus` is PENDING, IN_TRANSIT,
  PARTLY_ARRIVED (B1), ARRIVED; `paymentMethod` is CASH, BANK_TRANSFER, MOBILE_WALLET, plus
  `BANK` for old rows stored as `bank`.
- **Unit tests did not exist** in apps/web. Added Vitest + Testing Library + jsdom
  (`npm run test:unit`, `vitest.config.mts`, `src/**/*.test.ts[x]`); Playwright is untouched.
  Vitest pins TZ=UTC so the Cairo tests fail if the browser's day is used.
